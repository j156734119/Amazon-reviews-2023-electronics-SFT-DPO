# Legacy materials

This directory preserves the original course project without modifying its
contents:

- `Fine_Tuning_DistilBERT_for_Three_Class_Sentiment_Classification_of_Amazon_Electronics_Reviews.ipynb`
- `AIDL_Assignment_LIN,FANGXING_u5736310.pdf`

The notebook trained a DistilBERT encoder for rating-derived three-class
sentiment classification. It achieved 0.8578 test accuracy and 0.6777 macro-F1
after one epoch, with a Neutral-class F1 of 0.3531.

Those results motivate the current project but are not directly compared with
the generative Base/SFT/DPO policies because the task, output space, and primary
metrics are different.
